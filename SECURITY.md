# Kebijakan Keamanan

## Versi yang didukung

Hanya versi terbaru di branch `main`.

## Melaporkan celah keamanan

Jangan buka issue publik untuk celah keamanan.

Pakai fitur **Report a vulnerability** di tab **Security** repo ini
(<https://github.com/aryaxzell/sakuku/security/advisories/new>) supaya laporan tetap privat.

Sertakan langkah untuk mereproduksi, versi app, dan versi Android yang dipakai. Aku akan usahakan membalas sesegera mungkin.

## Catatan privasi

SakuKu bekerja 100% offline. Data transaksi hanya disimpan di database lokal perangkat, tidak dikirim ke server mana pun.
